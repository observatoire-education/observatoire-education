# Logo tableau noir Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remplacer le carré bicolore du header par le logo « tableau noir à courbes » et donner au site un favicon.

**Architecture:** Une seule source pour la version simplifiée, `site/public/favicon.svg`, servie comme favicon et importée en `?raw` dans le header (pas de copie du dessin). La version complète vit dans `site/public/logo.svg`. Le PNG iOS est généré une fois et commité ; aucune dépendance ajoutée.

**Tech Stack:** Astro (sortie statique), CSS du site (`obs.css`), `bun test` + linkedom (`tests/site.ts`).

**Spec:** `docs/superpowers/specs/2026-11-24-logo-design.md`

## Global Constraints

- Couleurs craie : violet `#9d8cff`, ambre `#f5c04a`, ardoise `#1b1f30`, bois `#9a7444`, axe `#e9e9e9` opacité 0,55 — identiques en clair et en sombre.
- Public = trait plein + points pleins ; privé = tirets + points creux (remplis ardoise). Courbes presque plates et presque parallèles, jamais croisées.
- Coordonnées de la spec (repère 64 × 64), à reprendre telles quelles.
- Aucune dépendance ajoutée à `package.json`.
- Commits en français, préfixe `feat:` comme l'historique.

## Review Focus

1. Mode sombre : l'ardoise du header doit rester visible sur `--surface` `#151826` (contour) — vérifier visuellement les deux thèmes, y compris `data-theme` forcé.
2. Mobile < 720 px : le nom est masqué, le logo seul doit garder sa taille et rester un lien accessible (le lien garde un nom accessible via le `<span>`, même masqué par `display:none` → ajouter `aria-label` au lien).
3. Le SVG inséré dans le header ne doit pas entrer en collision d'`id` (le dessin n'en utilise aucun ; le test le vérifie).
4. Impression (`FicheA4`) : vérifier que le header imprimé n'affiche pas d'ardoise sombre si le header est déjà masqué à l'impression (contrôle visuel seulement).
5. Le test « anti-palmarès » reste vert (aucun texte ajouté).

**Files:**

**Interfaces:**
- Produces: `site/public/favicon.svg` — `<svg xmlns viewBox="0 0 64 64">`, premier enfant `<rect class="ardoise" x="2" y="2" width="60" height="60" rx="12" fill="#1b1f30"/>`, sans `id`, sans `width`/`height` fixes. Utilisé tel quel par la Task 2.

- [ ] **Step 1: Écrire le test qui échoue** (dans le `describe` existant de `site-transverse.test.ts`)

```ts
test("favicon SVG et icône iOS déclarés et publiés", () => {
  const d = doc("sources");
  expect(d.querySelector('link[rel="icon"][type="image/svg+xml"]')?.getAttribute("href")).toBe("/favicon.svg");
  expect(d.querySelector('link[rel="apple-touch-icon"]')?.getAttribute("href")).toBe("/apple-touch-icon.png");
  const svg = page("favicon.svg");
  expect(svg).toContain('viewBox="0 0 64 64"');
  expect(svg).not.toMatch(/\bid=/);
  expect(octets("apple-touch-icon.png")).toBeGreaterThan(500);
  expect(octets("logo.svg")).toBeGreaterThan(200);
});
```

(importer `octets` depuis `./site.ts`.)

### Task 2: Logo dans le header

**Files:**
- Modify: `site/src/layouts/Base.astro:32` (`.brand`), `site/src/styles/obs.css:33` (`.brand i`)
- Test: `tests/site-transverse.test.ts`

**Interfaces:**
- Consumes: `site/public/favicon.svg` (Task 1), importé par `import logo from "../../public/favicon.svg?raw";`

- [ ] **Step 1: Écrire le test qui échoue**

```ts
test("le header porte le logo tableau noir, pas le carré bicolore", () => {
  const a = doc("sources").querySelector("header .brand")!;
  expect(a.querySelector("i")).toBeNull();
  const svg = a.querySelector('svg[aria-hidden="true"]');
  expect(svg).not.toBeNull();
  expect(svg!.querySelector("rect.ardoise")).not.toBeNull();
  expect(a.getAttribute("aria-label")).toBeTruthy();
});
```

- [ ] **Step 2: Lancer, vérifier l'échec**

Run: `bun test tests/site-transverse.test.ts -t header`
Expected: FAIL (`<i>` présent).

- [ ] **Step 3: Remplacer `<i></i>`** par `<Fragment set:html={logo.replace("<svg", '<svg aria-hidden="true" focusable="false"')} />` ; ajouter `aria-label={NOM_SITE}` au lien `.brand`.

.brand svg .ardoise { stroke:color-mix(in srgb, var(--ink) 22%, transparent); stroke-width:3; }

(Le contour, quasi invisible en clair sur l'ardoise sombre, détache l'ardoise de la barre en sombre.)
