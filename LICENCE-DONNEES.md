# Licence des données

Les données retraitées publiées par l'Observatoire citoyen de l'éducation en France (fichiers JSON du site, archives des sources publiées en GitHub Releases, fichiers Parquet téléchargeables) sont diffusées sous **Licence Ouverte 2.0 (Etalab)** :
<https://www.etalab.gouv.fr/licence-ouverte-open-licence/>

Elles proviennent de jeux de données publics diffusés eux-mêmes sous Licence Ouverte (ministère de l'Éducation nationale, DEPP). Chaque page du site indique, pour chaque chiffre, le producteur, le titre du jeu, le millésime, la date de collecte et un lien vers la donnée brute archivée.

Réutilisation : mentionner « Observatoire citoyen de l'éducation en France » et la source d'origine indiquée sur la page ou dans le fichier.
